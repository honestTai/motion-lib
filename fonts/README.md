# 字体 / Fonts

## 中文

| 目录 | 字体 | 用在 | 来源 | 许可 |
|---|---|---|---|---|
| `ysbth/` | 优设标题黑 YouSheBiaoTiHei | 标题、大数字 | 优设网，网页分包版来自 [chinese-free-web-font-storage](https://github.com/KonghaYao/chinese-free-web-font-storage)（npm `@chinese-fonts/ysbth`） | 优设网声明免费商用，详见 <https://chinese-font.netlify.app/#/fonts/ysbth> |
| `smiley/` | 得意黑 Smiley Sans（斜体） | 字幕、标签 | [atelier-anchor/smiley-sans](https://github.com/atelier-anchor/smiley-sans) v2.0.1 | SIL OFL 1.1，见 `smiley/OFL.txt` |
| `pixel/` | 缝合像素 Fusion Pixel 12px 简中 | 像素风皮肤 | [TakWolf/fusion-pixel-font](https://github.com/TakWolf/fusion-pixel-font) 2026.11.10 | SIL OFL 1.1，见 `pixel/OFL.txt` |

正文默认用系统的苹方（PingFang SC）、等宽用 SF Mono / Menlo，不随仓库分发。
在非 macOS 机器上渲染时，请装 Noto Sans SC 作为正文替代。

## English

| Directory | Font | Used for | Source | License |
|---|---|---|---|---|
| `ysbth/` | YouSheBiaoTiHei (优设标题黑) | Titles, big numbers | YouSheJi (uisdc.com); the web subset build comes from [chinese-free-web-font-storage](https://github.com/KonghaYao/chinese-free-web-font-storage) (npm `@chinese-fonts/ysbth`) | The publisher states it is free for commercial use; see <https://chinese-font.netlify.app/#/fonts/ysbth> |
| `smiley/` | Smiley Sans (得意黑), oblique | Subtitles, labels | [atelier-anchor/smiley-sans](https://github.com/atelier-anchor/smiley-sans) v2.0.1 | SIL OFL 1.1, see `smiley/OFL.txt` |
| `pixel/` | Fusion Pixel 12px, Simplified Chinese | Pixel theme | [TakWolf/fusion-pixel-font](https://github.com/TakWolf/fusion-pixel-font) 2026.11.10 | SIL OFL 1.1, see `pixel/OFL.txt` |

Body text defaults to the system PingFang SC, and monospace to SF Mono / Menlo; neither is distributed with the repo.
When rendering on a non-macOS machine, install Noto Sans SC as the body-text substitute.
