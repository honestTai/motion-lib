# assets/puppet

The demo mascot used by `examples/puppet/` and `examples/stage/`. Original artwork drawn for this repository as SVG
(sources in `src/`); released under the repository's MIT license.

| Files | What |
|---|---|
| `bot_m0.png` `bot_m1.png` `bot_m2.png` | Single-pose bust: mouth closed / half open / wide open |
| `bot_<pose>_m0..2.png` | Bust poses `wave` `point` `think` `cheer`, three mouth frames each |
| `mini_idle.png` `mini_walk1.png` `mini_walk2.png` `mini_cheer.png` | Full-body mini actor for `data-make="mini"` |
| `cut_desk.svg` | One full-screen illustration for `cutaway` |

Rig data for `fx-puppet.js` (source pixels, 600×600, shared by every bust pose): eyes `238,236,64,76` and `362,236,64,76`, neck `300,400`.
